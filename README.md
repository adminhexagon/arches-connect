# arches-connect
Connect Build - Outreach tool

## Task list demo

A local task list for tracking outreach steps. Tasks are stored in this browser with `localStorage`. There is no server and no external account.

### Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually http://localhost:5173).

### Test

```bash
npm test
```

### Production build

```bash
npm run build
npm run preview
```

`npm run build` typechecks the app and writes a static bundle to `dist/`.
